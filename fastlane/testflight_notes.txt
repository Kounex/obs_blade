4.1.0 test build 7. New since build 6:

YOUTUBE CHAT EMOJIS
- Emojis draw inline in YouTube chat (standard set bundled; the app also learns a channel's own member emojis from the chat page)
- Emoji picker in the YouTube chat input: the channel's member emojis first, then the standard set (sign in to write)
- Your own sent message shows your channel's name, not "Unknown"

CHAT (all platforms)
- Long-press a message -> user card now on YouTube + Kick too, with highlight / ignore
- One options sheet per chat: "All chats" (appearance, highlights, mute words, TTS) then the platform's own section; combined chat gets platform tabs + search over the merged timeline
- Search chat: has a back chevron, and can show messages your filters hide
- Sheet pages (options pages, mod presets, timeout / warn) slide into each other; back returns to where you came from; the selected message stays marked until the last sheet closes
- Busy chat at the 500-message cap: a sub / announcement already on screen must NOT fade in again when new messages arrive; a genuinely new notice still animates once
- Scrolled up in a busy chat: the rows you are reading stay put while new ones arrive below; back at the bottom the buffer trims again
- Combined chat: every platform's channel emotes render (e.g. a Twitch channel's 7TV / BTTV set), not just globals
- App to the background mid-chat and back: chat recovers on its own, in-flight requests finish

DASHBOARD
- Scene item inside a group: visibility and lock toggles act on the item itself
