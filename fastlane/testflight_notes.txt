4.3.1 test build 1 - remote access polish. Needs a Pro device paired with a PC (OBS Blade Remote app on the PC).

OBS BLADE REMOTE UPDATE (NEW)
- PC on an older OBS Blade Remote than the latest (0.4.3 today; e.g. keep 0.4.2 installed): connect -> once the dashboard is up, an "Update OBS Blade Remote" dialog with both versions, Share Link / Later
- Later, disconnect, connect again: no dialog this time; the globe in the dashboard bar has a small dot
- Globe -> the Remote Access sheet shows an "Update available" card under the PC with "Share Link to Your PC" and the page link
- Share Link: the share sheet opens with obs-blade.kounex.com/remote (AirDrop it to the Mac / send it to yourself); iPad: the popover is anchored
- Update the PC to the latest: dot and card are gone after the next connect / opening the sheet
- PC already on the latest: none of this shows

START OBS
- On mobile data, quit OBS on the PC, connect -> "OBS isn't running" -> Start OBS, lock the phone right away for ~1 min, unlock -> it connects (or the overlay is still up and connects once OBS is ready)
- With OBS Blade Remote quit on the PC: "Couldn't confirm OBS started"
- Start OBS with the app open the whole time still connects
- PC on an older OBS Blade Remote: the "OBS isn't running" dialog also names the update

PAIRING HINT
- On the Wi-Fi, quit OBS Blade Remote on the PC, globe -> Set Up Remote Access: after ~6 s a hint says what's missing on the PC, with the download link; Cancel still there
- Start OBS Blade Remote while it waits: the hint goes and it pairs

RELAY RESTART
- Connected through the relay while the relay updates (rare, at night around 04:00): back within a few seconds instead of a long reconnect

Also: upgrade over the store version keeps saved connections, pairing and settings.
