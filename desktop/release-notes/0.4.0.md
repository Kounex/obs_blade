The first release of OBS Blade Remote: control OBS from the OBS Blade app
from anywhere, not only on your Wi-Fi. End-to-end encrypted, no port
forwarding. Remote access is part of OBS Blade Pro.

**Which download?** Install one of the two on the PC running OBS:

- **OBS Blade Remote** (recommended): a small tray / menu bar app. It sees
  whether OBS is running and lets the app start OBS for you.
  macOS `.dmg` · Windows `-setup.exe` · Linux `.AppImage` (e.g. SteamOS)
- **OBS Blade Remote plugin**: runs inside OBS (Tools → OBS Blade Remote),
  nothing extra running. macOS `.pkg` · Windows `-setup.exe`

Both at once is fine - they hand over to each other.

**Setup:** in the OBS Blade app, connect to OBS on your Wi-Fi, tap the
globe on the dashboard, then **Set Up Remote Access**.

Notes: the Windows installers aren't code-signed yet - Windows may show
"Windows protected your PC"; choose **More info → Run anyway**. On Linux,
make the AppImage executable (`chmod +x`) and start it from your desktop.
